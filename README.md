🍳 Kitchen Inventory Management System
A web-based Kitchen Inventory Management System designed to efficiently manage kitchen ingredients, stock levels, expiry dates, users, and inventory activities. The system helps Admins, Chefs, and Delivery Partners monitor and manage kitchen inventory through role-based dashboards.
✨ Key Features
•	👨‍💼 Admin Dashboard – Manage users, inventory, and overall kitchen operations. 
•	👨‍🍳 Chef Dashboard – View available ingredients, use items, and monitor expiring stock. 
•	🚚 Delivery Partner Dashboard – Manage and track delivery-related activities. 
•	📦 Inventory Management – Add, update, delete, and track kitchen items. 
•	⏰ Expiry Notifications – Get alerts for items that are about to expire. 
•	🔔 Inventory Notifications – Track newly added and recently used items. 
•	🔐 Role-Based Access Control – Different permissions for Admin, Chef, and Delivery Partner. 
•	📊 Dashboard Monitoring – Quickly view important inventory information. 
🛠️ Tech Stack
Frontend: HTML, CSS, JavaScript
Backend: Node.js, Express.js
Database: MongoDB
Development Tools: Nodemon, MongoDB Compass
🎯 Objective
The main objective is to reduce food wastage, prevent stock shortages, monitor expiry dates, and simplify kitchen inventory management through a centralized digital system.
